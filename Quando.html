MANUALE TECNICO // SELF-HOSTING & DEPLOY

Questa web app è racchiusa in un singolo file HTML autonomo e sincronizza già gli eventi in tempo reale. Per ospitarla sul tuo dominio (GitHub Pages, Netlify, Vercel o server aziendale):

  1. Crea un progetto gratuito su Firebase Console.
  2. Attiva Authentication → Metodo di accesso → Anonimo e Cloud Firestore.
  3. Incolla le credenziali del tuo progetto nella costante YOUR_CUSTOM_FIREBASE_CONFIG in fondo al file:
const YOUR_CUSTOM_FIREBASE_CONFIG = {
  apiKey: "AIzaSy...",
  authDomain: "tuo-progetto.firebaseapp.com",
  projectId: "tuo-progetto",
  storageBucket: "tuo-progetto.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
LINK DIRETTI: Condividendo l'URL con parametro (es. ?event=evt_xyz), ogni membro del team aprirà direttamente la griglia dell'evento corrispondente.
